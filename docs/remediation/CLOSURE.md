## External prerequisites and deliberate limits

- Production merge/rollout, customer-record changes, provider-account connections and real emails remain outside this task. No hosted deployment or email-delivery receipt is claimed.
- Before an authorized production release, the existing operator must supply reviewed legacy ownership/provider mappings, install the recovery encryption key through the existing secret mechanism and run forward migrations/provisioning under the documented owners. These are concrete release configuration/data decisions, not invented verifier IDs or external issuers.
- Existing hosted backup retention, restore permissions/objectives and monitoring configuration were not inspected. Confirm them with the current provider/operator. Local restore evidence does not establish hosted policy.
- No purchasing form is activated while product/item/receiving workflow is incomplete. Node operational orders and .NET purchase orders remain distinct. No suppliers, associations, forecasts, confidence scores or financial impact are fabricated.
- No paid model, map, broker or monitoring subscription is introduced. External delivery and predictive models remain optional/unavailable. In-app review/notifications are real durable capabilities.
