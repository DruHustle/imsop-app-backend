# Unsupported historical Kubernetes examples

These manifests are archived design examples. They are not a supported production deployment path, do not pass current configuration/readiness qualification and must not be deployed. The active Kubernetes workflow has been retired. Node-only images and the Oracle multi-service bundle have different ports and process composition. Use [Oracle](../../deploy/oracle/README.md) and [current deployment inventory](../../docs/DEPLOYMENT.md). No cluster provisioning is required.
